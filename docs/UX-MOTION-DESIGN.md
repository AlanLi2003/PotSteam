# CNrecipe 组件动效设计（待视觉确认）

## 范围

保留现有页面框架、三个导航入口 Explore / My Kitchen / Saved、色彩与页面信息顺序。用户已选用第一轮方案 1 的圆形计时器。本文件为设计规范，不表示已实现或验证。

## 组件规则

| 组件 | 触发与反馈 | 建议时长 |
| --- | --- | --- |
| 悬浮胶囊导航 | 外壳与三个点击区固定；深绿选中胶囊从当前位置滑向目标，图标文字同步切换；内容仅轻微淡入，不横移整页 | 280ms，缓出 |
| 收藏 | 触下缩至 0.92；收藏后填砖红色，放大至 1.12 再回 1；取消退回描边；不改变按钮占位 | 240ms |
| 普通按钮 | 触下缩至 0.97，松开恢复；禁用态无动效 | 100–160ms |
| 备料勾选 | 底色变绿、勾线描画；不删除或移动已选行 | 180ms |
| 筛选标签 | 背景、边框、文字平滑换色；宽度不变 | 160ms |
| 食材抽屉 | 从底部进入，遮罩渐显；打开先暂停，关闭不恢复 | 280ms 进入 / 220ms 退出 |
| 步骤切换 | 文案轻淡入，进度条同步更新；避免整页滑动 | 180ms |

导航点击即切换目标状态；连续点击以最后一次为准，从当前视觉位置继续，不排队。重复点击已选入口不重播。保留现有点击导航，不新增滑动手势切页。收藏连续点击以最终状态为准，不重复播放叠加动画。保存失败时恢复原状态并显示明确提示。

## 计时器

保持标题、进度、说明、计时器、步骤操作、食材入口的原有顺序。仅扩展原计时器区域为直径约 180–200pt 的圆环，数字建议 48–56pt 等宽字形；暂停控制独立且点击区至少 44pt。小屏允许现有页面滚动，不通过缩小正文适配。

- 未开始：静态圆环，显示建议时长与开始按钮。
- 运行：进度环表达剩余时长，外部柔和光圈 2.4 秒一周期呼吸；数字保持稳定，不每秒弹跳。
- 最后 10 秒：琥珀色光圈，1.2 秒一周期呼吸，附“即将结束”文字；不频闪。
- 暂停：停止光圈与进度变化，显示“已暂停”和继续按钮。
- 到时：显示完成提示，沿用现有短提示后自动下一步与 Back 回退行为；不添加 Reset。
- 无 duration：不渲染计时器，也不留空白占位。
- 打开食材抽屉先暂停；关闭后仍暂停，用户在计时器点击继续。

## 可访问性与验收

减少动态效果时关闭位移、缩放、描画与呼吸，使用不超过 120ms 的透明度变化或直接切换。颜色必须配合文字/图标；焦点样式保留；不每秒播报倒计时，仅播报开始、暂停和到时等状态。

后续实现需检查：三入口无增删；胶囊滑动不挤动标签；快速连点无错位；收藏无布局跳动且持久化结果一致；抽屉暂停语义不变；计时结束仅前进一次；无计时步骤不留占位；小屏/大字体下控件可达；减少动态效果下所有操作可用。
