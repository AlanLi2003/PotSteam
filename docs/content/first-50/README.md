## 用量与内容处理

- 来源给出的范围采用明确端点，份数未明确时作为编辑分餐安排；时间包含必要的准备与浸泡，是备餐估计，不是实做计时。
- 原文明示按口味调节或按锅具加水/用油时，保留To taste或As needed；不把未知值编造成精确克数，亦不展示“0 to taste”。
- 整鸡、整鱼等按完整批次换算，避免缩减盐焗盐床或要求采购四分之一条完整鱼。

- source-register为主配方依据，配方事实之外的安全检查引用USDA官方温度指引；去除家庭鱼发酵教程、生禽冲洗和仅凭颜色判定熟度等做法。臭鳜鱼明确要求使用可追溯商业预处理原料并遵循标签。
