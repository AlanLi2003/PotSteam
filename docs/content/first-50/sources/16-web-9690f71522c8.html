烟火家的香菇炖鸡

0 人做过这道菜
收藏
 Seefirework
这个菜用走地鸡比较好，司务长用的清远麻公鸡
好的食材不需要过多的调料，简单的调味才能突显食材本身的鲜美
鸡肉不焯水，用炒制的手法去血气，可最大程度体现鸡汤的浓郁鲜美
炒过的鸡块炖制中几乎没有血沫，汤底很干净

用料  

净鸡块 800克
香菇 250克
生姜带皮 一块
大葱 一段
小葱碎 适量
枸杞 适量
料酒 1大勺
盐 适量
白胡椒粉 5克
油 适量

烟火家的香菇炖鸡的做法  

  1. 鸡块用温水洗净控水
    姜切片
    炒锅放底油，投入姜片鸡块翻炒，待鸡块发白投入料酒继续翻炒，炒至鸡骨头的断口不再冒血水，料酒蒸发完，关火

  2. 鸡块和姜片移入砂锅，炒鸡块的底油留在锅里备用

  3. 砂锅加足够的热水，加葱段大火烧开转小火炖鸡肉

  4. 鲜香菇洗净，用手轻轻攥出些水，略微出点水，松手不滴水即可，撕成小块备用

  5. 用炒过鸡块的底油炒香菇，炒至香菇吃透底油即可
    出了水的香菇会把底油全吸进香菇里，有了鸡油香气的加持，香菇炖出来非常好吃

  6. 鸡块炖制半小时后，捞出葱段，投入炒好的香菇，加入适量盐继续小火炖

  7. 准备5瓣带皮的蒜，保留最后的皮，洗净

  8. 鸡块炖制最后10分钟时加入蒜和白胡椒粉继续小火炖

  9. 五分钟后，挑出蒜和蒜皮不要，加枸杞继续炖5分钟即可

  10. 关火撒些小葱碎即成，盐味不足可调

    鸡肉炖多久取决于鸡肉质和你能接受的口感，这个鸡块不需要炖的完全酥烂，有点韧的口感就好吃
    小仔鸡45分钟左右
    麻公鸡1小时左右
