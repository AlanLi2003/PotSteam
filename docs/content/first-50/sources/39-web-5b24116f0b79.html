清香甘甜清热汤 补血养颜老少宜

标签： 字号： 大 中 小 访问量：

莲藕排骨汤

 

食材

排骨500g，莲藕1节，生姜1块，葱2根，料酒适量，盐适量

烹饪步骤

1. 葱洗净切段，生姜洗净切片，放一旁备用；

2. 莲藕去皮洗净后，切成大块，泡在水中备用；

3. 排骨洗净后斩成块，放入热水锅中焯去血水捞出，冲洗干净；

4. 把焯好的排骨倒入汤锅中，加适量料酒，倒水淹没排骨；

5. 再放入备好的姜片、葱段，盖上锅盖，大火烧开后小火煮15分钟；

6. 再把莲藕倒入锅中，小火继续煲1小时；

7. 煮好后加入适量盐搅拌均匀，即可盛出食用。

专家点评

这道汤品清香甘甜，老少皆宜。莲藕微甜而脆，可生食也可做菜，每百克鲜藕中含碳水化合物约20克，蛋白质1克，富含维生素C、钙、磷和膳食纤维等营养素。

莲藕是一种药食同源的食物，具有独特的清香味，可开胃健脾，补益气血，中医治疗中可用于收缩血管起到止血的作用。

这道汤中的排骨推荐选用猪的仔排，即肋骨部位的肉，瘦肉比例更高，富含优质蛋白和适量的脂肪。用仔排和莲藕煲汤，有辅助清热消痰、补血养颜的功能。

建议高血脂、脂肪肝、血糖高的人群少喝此汤，可改瘦肉炒藕片。
