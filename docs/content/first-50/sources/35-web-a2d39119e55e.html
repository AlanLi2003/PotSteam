选用鲜活草鱼、绍兴黄酒25毫升、玫瑰米醋170克……西湖醋鱼有了杭州地方标准

字体： 小 中 大
—2024—
12/06
08:08:57
2024-12-06 08:08:57 来源：杭州日报 记者 徐晟哲

　　做西湖醋鱼到底要用什么鱼？放几毫升调味料？要烧多久？用什么火？以前，不同的厨师有不同的做法，而从今往后，杭州西湖醋鱼有了统一标准。

　　12月5日，第二十四届中国（杭州）美食节——杭帮菜（系列标准）发布暨“食在杭州·我们的家宴”杭帮菜美食月活动在西子湖畔杭州楼外楼举办。活动现场对西湖醋鱼进行了重新定义，从食材、调味料、烹饪工艺、烹调设备等方面，全方位规定了西湖醋鱼的地方标准：西湖醋鱼应选用鲜活草鱼（750克左右最合适），调料有25毫升的绍兴黄酒、170克的浙江玫瑰米醋等……

　　西湖醋鱼杭州地方标准的出台，在杭州餐饮圈“炸开了锅”。现场多位杭帮菜专家表达了对杭帮菜未来发展的憧憬，期待杭帮菜越来越受到更多年轻人的欢迎。

　　“以往的杭帮菜，主要是师傅带徒弟，通过口头教授、亲身示范的方式来传承烹饪方法，缺乏严谨性。现在通过杭帮菜业内专家、杭州各大知名酒楼和社会各界的共同努力，运用科学的方法，精确地研究出了一整套西湖醋鱼的选材、制作标准。类似于麦当劳、肯德基那样的标准，这对打造具象化的杭帮菜IP有着很关键的作用。”杭州楼外楼酒楼行政主厨高征钢表示。

　　对于这次标准的出台，浙江旅游职业学院厨艺学院院长金晓阳有自己的看法：“这次的地方标准已经很完善，精细到鱼的养殖需要什么条件，调料是什么地方产的，甚至要用量杯、电子秤等工具来确定调料的用量。作为教育工作者，我深知杭帮菜文化传承的重要性，目前我们学院有两个班级、70位学生正在深入学习标准化杭帮菜的烹饪方法。”

　　中国烹饪大师、杭帮菜领军人物胡忠英也来到了现场，他对西湖醋鱼杭州地方标准不吝溢美之词：“杭帮菜要发展、要走向世界，一套成体系的、系统化的行业标准是必不可少的。中国美食博大精深、源远流长，却缺乏像法国菜、美式快餐那样的一整套标准流程，这是杭帮菜与国际接轨的重要一步。据我估计，目前这套标准可以沿用很长时间，短期内不会有大的变动。”

　　据悉，本次西湖醋鱼地方标准由杭城知名餐饮品牌楼外楼与湖畔居共同参与制定。

　　作为杭帮菜的代表品牌，楼外楼一直以来坚守传统烹饪技艺，其12道省级非遗菜肴更是杭帮菜文化的瑰宝。此次，楼外楼作为杭帮菜的代表品牌，此次还在传承非遗技艺的基础上，联合湖畔居、金溪山庄一起推出了名楼宋嫂群仙羹、秋梅啫鱼脯、鲜椒豉汁焗甲鱼、鲍鱼炆鸭舌、石锅沙姜鲍鱼鸡、新派咸件儿、古树红茶陈卤鸭、陈皮萝卜干蒸江鳗、茶香蟹斗、蕈油蒸桂鱼等10道杭帮菜创新菜。

　　此次推出的新菜，在传承非遗技艺的基础上，在从食材选择、烹饪工艺及口味呈现上均进行了精心设计与创新，既保留了杭帮菜“鲜、香、脆、嫩、爽”的传统风味，又融合了现代健康饮食理念与多元文化元素，为消费者带来全新味觉体验。

　　本次活动由杭州市商务局主办，杭州楼外楼实业集团股份有限公司、杭州市餐饮协会联合承办，杭州多家知名餐饮企业与浙江商业职业技术学院共同协办。
