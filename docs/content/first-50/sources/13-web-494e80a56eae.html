顯示部份食材

*使用前請務必將水箱加滿水。作法2利用細濾網過濾掉結締組織及泡沫，才不易產生結塊口感，蒸蛋吃起來會更加細緻順口。

料理步驟

  • Step1.

    豬絞肉以開水燙過後瀝乾備用。

  • Step2.

    將雞蛋及所有調味料拌勻後以細濾網過濾掉結締組織及泡沫。

  • Step3.

    將蛋液裝碗，放入肉末。放上蒸烤架與蒸烤盤。

  • Step4.

    放入蒸氣烘烤爐NU-SC300B，選擇【電腦烹調2：蒸蛋，4顆】，取出後灑上蔥花即可。

※食材份量與烹調時間供參考，可依個人口感喜好進行調整。
