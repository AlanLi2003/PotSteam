本帮菜大师亲传糖醋小排做法，比例最关键

2023-03-29 09:34
来源：澎湃新闻·澎湃号·湃客
听全文
字号

原创 淘最厨房

当一道菜落入寻常百姓家，随处都有人挥起锅铲烹制一番，随着调料品的赠多，样式更是层出不穷。

而有一群人，自打学厨那一天起就死板恪守标准。

我们简单粗暴，直接请来了书上这位“厨神”任德峰老师，并且用酱油、米醋和白糖这些基础材料，做出了糖醋小排的原型。食材纯粹简单，但味道足以碾压街头巷尾80%的本帮菜馆子。没有淀粉和勾芡，但酱汁挂得住每一块小排，光亮而有精神气。任大师说：“它就该像20多岁健身的小伙子。”在固定的原材料里拿捏出最佳的平衡，才是传承最难最严格的地方。

师傅（李伯荣大师）当初就是这么教他的，而他今天也要一比一的告诉每一个人。

● 食材准备

/ 主食材 /：500g肋排

/ 配料 /：生抽、老抽、米醋、糖、葱姜、料酒

● 制作过程

计量单位：

以右图中的勺子大小为准

1调羹 = 15 ml

1

处理肋排

❶ 将肋排改刀成大小均匀的长条，保持宽：长 = 1:2。

❷ 取一锅水烧开，倒入肋排焯水至变色，可以有效去除猪肉的腥味。2

调味焖煮

❶ 开大火，锅里倒入2调羹（30ml）油，放3片生姜和1把小葱煸香，倒入焯好水的肋排，煸炒20秒。

关于 “酱油”

❷ 加入1调羹（15ml）料酒、2调羹（30ml）生抽和1调羹（15ml）老抽。

传统的糖醋小排用的是黄豆酱，

现在很难再买到，

所以在家 老抽：生抽=1 : 2！

关于 “糖和醋”

❸ 加2调羹（30ml）米醋和3调羹（45ml）糖，翻炒均匀，再倒入淹没肋排的开水。

要想酸甜平衡，

记住 糖：醋 1 : 1，

为保留酸味，其中1调羹醋，

出锅前才能放！

关于“火候”

❹ 加盖焖煮5分钟后转中火，焖煮30分钟，当肋排裹上油亮的酱汁，最终再淋入1调羹（15ml）米醋，翻炒两下后关火出锅。

中火让酱汁不停煮沸翻滚，

可以避免油汁分离，

影响卖相和食欲！

没有一粒淀粉的糖醋小排，酱汁也格外清亮有光泽，周遭的空气都随着酸溜溜并泛着甜。

我们拍摄时曾担心过，太不花里胡哨的它可能不够抓看客眼球，嗅觉和味觉的加持才能使它挥出暴击，但我们还是坚信，每一位正在阅读文字的是识货行家，会愿意在家试上一试。
