传统本帮菜 糖醋小排

0 人做过这道菜
收藏

由浦东梅龙镇学校特约陈建新大师讲授实操最正宗的传统老上海家喻户晓的糖醋小排，陈老师师承一代宗师李伯荣，是李伯荣的关门弟子，舌尖上的中国曾特别专辑介绍过。60 70 80后的都应该能体会曾经的原汁原味，随着时代变迁，新派上海菜系不断创新，菜谱也层出不穷，我们这里介绍的是最初的本帮菜，希望记忆不会抹去，本帮菜文化能有所传承！

传统本帮菜 糖醋小排的做法  

  1. 桂皮八角香叶

  2. 葱姜

  3. 我们选用肋排，其他部位做法一样哦，肋排肉质比较好

    洗干净后用厨房用纸吸干水分，毛巾吸干也可以，沥干也可以，如果要马上做吸干是最快的

    上浆（味精 盐 玉米淀粉）和小排拌均匀(用手)

  4. 倒入油至6成热，下小排油炸

  5. 表面金黄色捞出

  6. 适量油热锅，热锅冷油，下葱段，姜片，香料翻炒，沥油(保留香料)

  7. 放入冰糖适量，糖，加一点点水，加入小排

    冰糖可以用小冰糖，大块的太慢

    冰糖使色泽更亮

  8. 加入一包米醋(袋装)和康乐醋，加一点水，加盐。烧一会，大约一分钟

    再加入镇江醋，因为醋随着烧锅不断挥发掉，所以需要二次加入，然后慢慢烧

    注意⚠️水和原料一样平

    注意⚠️如果颜色不够，可以用镇江米醋

    注意⚠️试汤味，不够甜加糖，生抽调鲜味，味道合适就等收汁

  9. 翻炒均匀

  10. 完成✅
