  • 請問為什麼排骨不用先燙過呢？

    2 年前

    燙過的排骨已經損失鮮味了。但是湯色會比較清澈。用電鍋或是電子壓力鍋通常浮沫很少。不燙也是沒問題的。煮好看有浮沫覺得礙眼可以撈。 浮沫就是些血水及蛋白質成分不是什麼雜質。 燙過表面再切開這些依然有，不可能再切開再燙。 如果排骨或肉是在傳統市場買的那就燙，個人覺得髒或是不新鮮（灰塵⋯⋯還有未冷藏，表面接觸常溫都開始長細菌了），至少能清潔與消毒表面。
