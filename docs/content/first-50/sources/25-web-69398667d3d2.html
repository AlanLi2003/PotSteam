酸菜鱼

酸菜鱼肉质细腻，汤汁酸香鲜美，鱼片嫩黄爽滑，微辣不腻。

菜单号
42

约 30分
难易程度
★★
密封/排気：
密封

关键步骤

1.
准备好所有食材。
2.
将鱼去头、剔骨、切片。
3.
鱼片放入大碗中，加入少许盐、胡椒粉、料酒、淀粉、鸡蛋抓匀入味。
4.
将鱼头、鱼骨、鱼片、洗净切成块的酸菜及其他配料加入锅中，加水合盖。
5.
(PC-MA2)在产品上选择“营养蒸”功能，按设定时间“+”“-”键，将显示时间调整:0：07，将排气阀拨到密封处，再按“开始”键启动功能。
5.
(KPC-MA2)在产品上选择“酸菜鱼”功能（自动功能/分类选择/肉类/酸菜鱼），按“确定”键，根据提示界面调整排气阀位置，再按“确定”键启动功能。
6.
烹饪结束，将锅内食物搅拌均匀后出锅，即可享用美食。
